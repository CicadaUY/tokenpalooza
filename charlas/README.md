## Agregar una charla

1. Copiar [`_plantilla.md`](_plantilla.md) con un nombre corto (por ejemplo `apellido.md` o `apellido-tema.md`).
2. Completar los datos y subir los materiales (diapositivas, notebooks) a una carpeta con el mismo nombre, o enlazarlos.
3. Agregar la charla a la tabla de esta página y al [cronograma](../README.md#cronograma).
